## 2. 目标与边界

构建单容器多 GPU 视频去马赛克智能加速流水线：先通过 `1 fps` 全片预扫识别有效马赛克区间并跳过无码片段（无码段采用 NVENC `5M` 硬件快速重编码对齐流参数），同时利用人体姿态关键点与几何双框拓扑自动剔除男优及路人头像马赛克，再将有效马赛克片段分发至单容器内多张 GPU 执行渲染大块与跨轨迹并行修复，最终通过 FFmpeg 无损拼接与混流统一输出 `.mp4`（`HEVC/hev1`）。

公开技术文档只记录算法参数、相对路径、模块职责与匿名测试指标，不写入具体素材片名、服务器主机名、网络地址、凭据或私有部署路径。
